本模块为仓库顶层，仅包含三份无代码文件，承担“对外契约 + 项目门面”职责：
- `README.md`：全局入口文档，给出后端 FastAPI+LangGraph、前端 React+Vite、Skill 扩展系统、工作空间记忆、WebSocket/SSE 等整体架构概览与快速开始命令，并列出目录结构与技术栈说明。
- `.gitignore`：统一排除 Python/Node 构建产物（`__pycache__`、`node_modules`、`dist/`）、`.env` 及 IDE 配置、日志和 `backend/storage/` 运行数据，确保仓库只保留源码与 Skill 定义。
- `polystudio-client/SKILL.md`：以 OpenAI Skills 规范（YAML frontmatter `name`/`description`）描述的外部客户端协议——`POST /api/chat` 返回 SSE（delta/tool_call/tool_result/skill_matched/error/[DONE]），并附带画布管理、文件上传、WebSocket `/ws/{canvas_id}` 订阅等 API 参考。
依赖方向单向向外：本模块不引入任何后端/前端代码，仅作为“对外契约”被 OpenClaw 等外部 Agent 消费；实际实现位于同级的 `backend/`、`frontend/` 目录。
